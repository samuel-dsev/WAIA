Solicitação de exclusão de dados

Para solicitar a exclusão de dados pessoais tratados pelo chatbot do Capitão Mor:

  1. Envie um e-mail para promarketing288@gmail.com.
  2. Use o assunto Exclusão de dados do WhatsApp.
  3. Informe o número do WhatsApp com código do país e descreva quais dados deseja excluir.
  4. Aguarde nosso contato para uma verificação razoável de identidade antes da exclusão.

Importante: nunca envie senha, código de acesso, PIN ou código recebido por SMS.

Após a verificação, removeremos os dados sob nosso controle que não precisem ser mantidos por segurança ou obrigação aplicável. Dados tratados diretamente pela Meta/WhatsApp ou pelo Google também estão sujeitos aos procedimentos desses fornecedores.
